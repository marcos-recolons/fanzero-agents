# Privacy notice: FanZero Discover & Plan

Publisher: **Marcos Recolons**. This notice covers the `fanzero-discover` static planning plugin, version 1.2.0. Support is available through [the integration repository's issues](https://github.com/marcos-recolons/fanzero-agents/issues).

## What this package does

The plugin supplies bundled instructions and an icon. Its workflow uses only context you provide in your conversation and returns drafts there. It does not read project files, request credentials, create accounts, run code, connect tools or make network requests. It has no publisher-operated backend, data collection, transmission, storage or telemetry. The publisher does not receive your conversation through this plugin, and the plugin has no personal-data collection mechanism or retention store.

## Your AI client

The AI client and its provider process the conversation used for planning. Their policies, applicable service or business agreements, and your organization's settings govern conversation handling, storage, retention and controls. This plugin does not set or override those rules. Consult the provider's primary documentation:

- [OpenAI privacy policy](https://openai.com/policies/privacy-policy/)
- [Anthropic privacy policy](https://www.anthropic.com/legal/privacy)

## Separate handoffs and support

Public links in the package let you choose a manual visit or a separate workflow. The plugin does not open those links or send data to the FanZero application. This notice applies to the static planning package; the hosted FanZero service and separate FanZero Publish workflow have different data behavior and are outside this notice's scope.

If you voluntarily open a GitHub support issue, GitHub handles that information under its own policies and the issue may be public. Do not include credentials or private game files in a public issue.

## Intended audience

This planning plugin is intended for adult developers and content creators considering commercial launches. It does not offer a service for minors or collect age-verification information.
