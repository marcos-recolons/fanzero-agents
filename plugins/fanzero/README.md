# FanZero Publish

Find a place to distribute your indie game and connect with influencers who can bring an audience to its launch. This plugin gives Codex and Claude Code a publishing skill for preparing a complete reviewed listing and revenue-share offers on [FanZero](https://fanzero.app).

Invoke `fanzero-publish` in Codex or `/fanzero:fanzero-publish` in Claude Code. Start with an assessment or draft; submitting a game needs a clear publishing request and approval of its revenue-share terms. The listing includes images or videos, a description, platform links, individual prices and currencies or a clear monetization model. Prefer the direct original link when the game is easy to play online, preserving online features, accounts, multiplayer, rankings and purchases. Publishing authorization does not authorize an adaptation. A hosted preview is allowed only when representative of the original, played successfully in FanZero's sandbox and better than the direct link for a concrete reason; agent uploads carry truthful `preview_review` evidence. If any criterion is false or unknown, omit the build. A qualifying upload needs offline HTML, bundled assets, an `index.html` entry and at most 8 MB and 1000 files. An existing misleading preview can be retired with `remove_preview: true` and the complete dossier on the existing listing. No port or playable slice is required to list a game. The publishing workflow submits the complete listing and, when needed, approved studio details with one idempotent `publish_game` call.

The plugin contains instructions and an icon. It has no hooks, executable dependencies, automatic MCP connection or embedded credentials. Installing it does not create a studio, publish a game or approve an influencer. For optional manual connection instructions, see the [integration repository](https://github.com/marcos-recolons/fanzero-agents) and [current agent guide](https://fanzero.app/agents.md).

## Data when using FanZero

The skill has no storage or telemetry of its own. If you choose a manual MCP or HTTPS connection, your agent sends data to `https://fanzero.app`: studio details and any contact you provide, listing content, media and platform URLs, prices, monetization, any optional build files, pact terms and influencer action schedules, and after a pact's window its settlement: each platform's net revenue, line notes and any platform report files you attach (remove buyers' names and emails first). Studio calls also send your API key for authentication. FanZero stores accounts, submitted builds and listings, pact records, and settlements with their report files. `check_build` processes the supplied listing and optional build without saving it as a draft or submission. Account, publication and pact records currently have no automatic deletion or configured retention deadline; they may remain stored for more than 30 days.

New pacts start their 28-day revenue share at the first proposed action date, with one studio approval and no proof stage. After the window, the studio declares each platform's net revenue from that platform's own report (`submit_settlement`, with the owner's approval) and the influencer accepts or disputes it. FanZero records the agreement and the settlement; the studio pays the influencer directly.
